# TRACMS Training Details Page Simplification Plan

## Goal

Make the training details page simple, professional, and easier to scan.

## Problem

The current page feels too heavy because it uses:

- too many summary cards
- too many feature cards
- long panel descriptions
- repeated field groupings

## Design Direction

- Remove the top summary stat cards
- Reduce the page into fewer core sections
- Present record fields in clean key-value blocks
- Keep workflow actions and certificate layout available, but make them calmer
- Remove repeated wording where the page already provides enough context

## Recommended Structure

### Header

- Training title
- Short copy only
- Actions:
  - `Back to trainings`
  - `Edit`

### Section 1: Overview

One clean panel with the most important training context:

- status
- schedule
- registration deadline
- modality
- venue
- capacity

### Section 2: Record Details

One clean panel for core government record fields:

- reference
- category
- training type
- organizer
- attendance method
- certificate type
- minimum attendance
- evaluation required

### Section 3: Description

One panel for:

- description
- objectives
- target participants
- participant qualification

### Section 4: Workflow

One panel for:

- current workflow status
- next action
- office/division context
- publication date
- workflow action form

### Section 5: Approval History

Keep the audit trail as a separate panel with simple event rows.

### Section 6: Certificate Layout

Keep the certificate layout feature, but present it as a lower-priority customization panel instead of a dominant section.

## Implementation Rule

Keep the existing training workflow and certificate layout behavior intact.

Only simplify the visual structure and wording.
