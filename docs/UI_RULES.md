# TRACMS UI Rules

- No custom buttons when `<.button>` can express the action.
- No raw HTML inputs when `<.input>` supports the control.
- No random Tailwind colors or isolated visual themes.
- Reuse card, panel, table, badge, alert, empty-state, and loading patterns.
- Create or extend a reusable component before duplicating a page pattern.
- Keep copy concise, official, and task-focused.
